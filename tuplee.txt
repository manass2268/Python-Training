Tuple is a immutable object. a tuple can not be changed in any way once it is created.

A tuple is defined in the same way as a object except that the whole set of elements are enclosed in parenthesis() instead of square bracket[]

Important
	  
Tuple can have any number of items and they may be of different types (int,float,list,string,etc)
a tuple can also be created without using parenthesis. this is known as tuple packing
==> tup=1,2,3
==> print(tup) #opt- (1,2,3)

3. Tuple unpacking is also possible
==> a,b,c=tup
